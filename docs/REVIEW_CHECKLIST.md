# QA Review Checklist

- [x] Document four intentionally introduced baseline defects (#1-#4).
- [x] Explain likely root causes using 5-Why summaries.
- [x] Compare source code against documented requirements.
- [x] Document severity and expected acceptance criteria.
- [ ] Compile source for Arduino Uno.
- [ ] Run threshold boundary tests.
- [ ] Validate actual ADC reference voltage.
- [ ] Test sensor disconnection and hardware output behavior.
- [ ] Close issues only after relevant evidence is attached.

**Review outcome:** Documentation complete for static analysis; runtime acceptance is pending. A pull request review is not evidence of physical testing.
